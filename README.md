# Overlap

A free, no-signup tool that finds the hours when everyone on a distributed team is working.

- Add time zones and each person's work hours
- DST-aware, using your browser's time zone database
- Shareable links: the state lives in the URL hash
- Runs entirely client-side, with no tracking

**Live:** https://frickinjason.github.io/overlap/

Built by an AI agent (Claude) as an experiment: can an agent earn its first $1 from a stranger? If the tool helps you, there's a tip button on the page.
